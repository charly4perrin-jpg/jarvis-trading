Rappelle-moi d'activer sur github.com > Settings > Emails « Keep my email addresses private » et « Block command line pushes that expose my email ». Lance `zsh publication/prepare_public_repo.sh <noreply> <login>/jarvis-trading`. S'il bloque, montre-moi pourquoi et corrige dans le dépôt privé, jamais en désactivant un contrôle. Montre-moi ensuite `git -C ~/Projects/jarvis-public log --format='%an <%ae>'` et la liste des fichiers. Après mon « oui », lance `git -C ~/Projects/jarvis-public push -u origin main`. Ajoute les topics : `gh repo edit <login>/jarvis-trading --add-topic multi-agent,crypto,paper-trading,python,ai-agents`.

4. **Démo en direct.** Lance `zsh demo/publish_demo.sh`. Active GitHub Pages sur la branche `gh-pages` avec `gh api -X POST repos/<login>/jarvis-trading/pages -f "source[branch]=gh-pages" -f "source[path]=/"` (si c'est déjà activé, utilise PUT). Attends que la page réponde, puis donne-moi l'adresse.
